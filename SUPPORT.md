# Support & Community Help

Welcome to OpenPost support! Because OpenPost is 100% free, community-driven, and open-source, support is handled through transparent public channels.

---

## 💬 Getting Help

| Topic | Channel | Best For |
| :--- | :--- | :--- |
| **Questions & Ideas** | [GitHub Discussions](https://github.com/azlanabdulla/OpenPost/discussions) | Feature ideas, general questions, workflow tips |
| **Bug Reports** | [GitHub Issues](https://github.com/azlanabdulla/OpenPost/issues/new) | Reproducible application bugs, unexpected crashes |
| **Release Downloads** | [GitHub Releases](https://github.com/azlanabdulla/OpenPost/releases) | Binary installers (`.msi`, `.exe`, `.dmg`, `.AppImage`) |

---

## 🐛 Submitting a Quality Bug Report

When opening a bug report, please include:
1. **Operating System**: Windows 11 / macOS 14 / Ubuntu 22.04, etc.
2. **App Version**: e.g., `v0.1.0`.
3. **Reproduction Steps**: Step-by-step description of what triggered the issue.
4. **Sanitized Diagnostics**:
   - If an error screen appears, click **"Copy Sanitized Diagnostics"** and paste the result into the issue.
   - All authorization tokens, passwords, and private keys are automatically scrubbed by OpenPost prior to copying.

---

## 🔒 Security Vulnerability Disclosure

If you discover a security vulnerability or potential credential leakage flaw, please **do not open a public GitHub issue**.

Instead, please submit a private advisory through [GitHub Security Advisories](https://github.com/azlanabdulla/OpenPost/security/advisories/new) or contact the maintainer directly. We will review and publish a patched release as quickly as possible.
