| Version | Supported          |
| :------ | :----------------- |

## Reporting a Vulnerability

We take the security of OpenPost seriously. Because OpenPost handles local network requests, tokens, and authorization credentials, security and data privacy are core design priorities.

If you believe you have discovered a security vulnerability in OpenPost, please **DO NOT** open a public GitHub issue.

Instead, please report it via GitHub Private Vulnerability Reporting or email:
`security@openpost.app`

Please provide:
- A description of the vulnerability.
- Steps to reproduce or a proof of concept.
- Potential impact and affected platforms (Windows, macOS, Linux).

We will acknowledge receipt within 48 hours and work with you to patch the issue before any public disclosure.
